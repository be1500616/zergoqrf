# Proposal: Feature Roadmap and Audit

## Goal
The goal of this change is to establish a clear architectural roadmap for ZERGO QR, audit all existing features for quality and test coverage, and documentation them within the Open Spec framework.

## Scope
- Complete audit of the current codebase (FastAPI backend, Flutter frontend).
- Mapping existing features to Open Spec capabilities.
- Verification of test infrastructure and addition of missing tests.
- Logical git commit organization for all audited features.

## Capabilities
1. **Infrastructure & Migrations**: Supabase schema and migrations.
2. **Backend Auth**: JWT-based authentication system.
3. **Backend Restaurant API**: Core restaurant management endpoints.
4. **Backend Menu & Orders**: Logic for menu management and ordering.
5. **Backend QR & Tables**: QR generation and table tracking.
6. **Frontend Onboarding**: Multi-step restaurant registration flow.
